# hate-speech-detection-transformers
Fine-tuned DistilBERT, RoBERTa, and HateBERT on HateXplain, building a soft-voting ensemble that reached 70.1% accuracy / 0.691 macro F1. Results showed domain pretraining beats class weighting, with the offensive class limited by annotator ambiguity. On Croatian FRENK, TF-IDF surpassed mBERT, exposing low-resource transformer limits.
